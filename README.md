# Pixelpret

Een eenvoudige pixelkralen-ontwerper voor kinderen, met een raster van 11 × 14 kralen. Werkt met tikken en vegen op iPhone en iPad.

Open `dist/index.html` of start lokaal vanuit `dist` met `python3 -m http.server 8080`.

Ontwerpen en de volledige terug/vooruit-geschiedenis worden op het apparaat opgeslagen. Patronen kunnen als PNG worden gedownload.

GitHub Pages publiceert automatisch de inhoud van `dist` na iedere push naar `main`.
